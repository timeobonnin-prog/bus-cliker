# 🚌 Bus Clicker

Un clicker inspiré de **Cookie Clicker**, mais version transports en commun.
Clique sur le bus, klaxonne, fais monter des passagers, débloque des lignes,
achète des klaxons, débloque des skins... et grimpe jusqu'au **Portail interdimensionnel**.

## ✨ Fonctionnalités

- 🖱️ **Clic principal** : klaxonne sur le bus et fais monter des passagers
- 🎵 **Klaxons procéduraux** : chaque clic joue un son généré par Web Audio (18 klaxons différents, répartis en 4 packs)
- 🚏 **12 bâtiments/lignes** : du *Chauffeur remplaçant* au *Portail interdimensionnel*
- ⚙️ **48 améliorations** (production ×2, clics ×2)
- 🎨 **8 skins de bus** (jaune classique, bleu urbain, rouge londonien, or massif...)
- 🏆 **19 succès** à débloquer
- 💾 **Sauvegarde automatique** dans le `localStorage` du navigateur
- 🌐 **Pseudo unique + amis en ligne** via une API Cloudflare Worker + GitHub
- 📱 **Responsive** (mobile, tablette, desktop)
- 🌙 **Mode sombre** automatique (via `prefers-color-scheme`)
- ♿ **Accessibilité** (labels ARIA, `prefers-reduced-motion` respecté)
